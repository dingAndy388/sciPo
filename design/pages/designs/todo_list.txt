===== 📘 Field Guide =====

Use the table below as a reference for each column.

^ Field  ^ Description  ^ Example  ^
| **Task**  | Brief description of what needs to be done.  | Homepage design final  |
| **Participants** | People involved. Use @username to link to user pages.  | @Jack, @Andy  |
| **Status**  | Current state. Common values: To Do / In Progress / Done / Blocked / Waiting. | In Progress  |
| **Due Date**  | Deadline. Format: DD-MM-YYYY.  | 2026-03-01  |
| **Priority**  | Importance level. Use High / Medium / Low or 🔴🟡🟢 etc.  | High  |
| **Notes**  | Extra info, links, dependencies, or comments.  | Awaiting UI review  |
