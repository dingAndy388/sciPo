# Science Potato · 多语言（i18n）（活文档 · v0.6.5）

> **用途**：UI 文案的唯一来源与扩展规则。框架在 `WP-5.10`（M1）建成，正式文案规模归 `WP-8.3`。
> 相关决策：`log.md` `D90`；风险 `R4`（i18n 越晚越贵）。

## 1. 文件与格式

| 项 | 约定 |
| :--- | :--- |
| 文件 | `Config/Strings.{locale}.json`（当前 `zh` / `en`） |
| 根结构 | `{ "Culture": "zh", "Strings": { "键": "文本", ... } }` |
| 键命名 | `域.对象`（点分、全小写）：`ui.generate`、`res.Food`、`terrain.plain`、`smoke.spawn` |
| 装载 | `I18nService.Load(IConfigSource, locales, defaultLocale)`；缺文件/坏 JSON 只记 warning，**不阻断启动** |
| 语言列表 | `CoreDependencies.Locales`（缺省 `zh,en`）、`DefaultLocale`（缺省 `zh`）、`Locale`（启动语言） |

## 2. 解析规则（必须记住的三条）

1. **顺序**：当前语言 → 默认语言 → 仍找不到就返回 `⟦key⟧` 并记入 `MissingKeys`。
2. **缺键可见**：绝**不**返回空字符串 —— 空字符串会让"少了一句文案"变成"看起来正常"。
3. **未装载语言**：`SetLocale("xx")` 返回 `false`（不抛异常）；切语言不该让游戏崩。

## 3. 使用方式（表现层纪律）

```csharp
II18nService i18n = ServiceContainer.Instance?.Services?.I18n;
if (_btn != null) _btn.Text = i18n.T("ui.generate");
```

- **只允许**写键：面板文案的赋值（`.Text` / `.Prefix` / `.PlaceholderText` / `.TooltipText` / `.Title`）若赋了字符串字面量，必须来自 `i18n.T(...)`
  —— 这条由 `I18nChecks.UiUsesKeysOnly` **自动检查**（它扫描 `Scripts/**/*Ui*.cs`）。
- 赋**代码常量/变量**（如 `_id.Text = DefaultMapId;`）不算写死文案，允许。
- 日志（`GD.Print`/`PushWarning`）仍然是中文，**不在**纪律范围内（开发输出不是玩家文案）。

## 4. 自动化护栏（`I18nChecks`，6 条）

| 检查 | 防的是什么 |
| :--- | :--- |
| 装载中英两套 | 文件缺失 / 结构写错 |
| 键解析 / 缺键可见 | 缺键静默变成空字符串 |
| 回退默认语言 | 某语言少一句就露出一串 key |
| **中英键集完全一致** | 双语项目最常见的静默漏译 |
| 切语言 / 未装载语言被拒 | 切语言时崩溃 |
| 面板只走键 | 文案重新散回代码 |
